# LinkedIn posts

LinkedIn menampilkan sekitar dua–tiga baris pertama sebelum "…see more", jadi hook
harus kuat di kalimat pertama. Post berisi link eksternal mendapat reach lebih rendah —
pilih salah satu strategi: (a) taruh link di komentar pertama milik sendiri, atau
(b) terima konsekuensinya karena target audiens butuh link langsung. Kedua versi
disiapkan di bawah.

Hashtag di LinkedIn cukup 3–5, ditaruh di akhir post.

## Post (English) — gaya storytelling profesional

> I got bored of writing the same way, so I built my own platform. And I made it free.
>
> For years my story projects lived in the same scattered pile: plot notes in one app, drafts in another, character sheets in a document I kept losing, and an AI chat window somewhere on a second monitor. Every tool solved one piece and none of them talked to each other.
>
> So over the past months I built OpenPlot AI — a desktop writing studio for Windows, macOS and Linux. It combines:
>
> → An AI chat that works with OpenAI, Anthropic, OpenRouter, Groq, Ollama, LM Studio, or any OpenAI-compatible endpoint — you bring your own key, and it stays on your machine
> → A story bible for worlds, characters, items and lore, with tags, search and cross-links
> → Chapters with statuses, focus mode, and version history
> → A three-act Story Flow board tied to your chapters
> → Writing statistics: daily goals, streaks and a 90-day heatmap
> → Export to Markdown, plain text or EPUB
> → A universal macOS build: one download for both Intel and Apple silicon (Windows and Linux too)
>
> Everything runs locally: SQLite storage, no account, no cloud, no telemetry. API keys are encrypted with the OS credential vault. The whole project is open source under MIT.
>
> If you write — fiction, worldbuilding, or campaigns — I'd genuinely like to hear what's missing. What would make this useful for you?
>
> Free download: https://github.com/mahakammoonlightstudio-beep/OpenPlot-AI/releases
>
> #OpenSource #IndieDev #Writing #AI #SoftwareEngineering
