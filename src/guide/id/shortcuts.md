# Pintasan keyboard

## Global
| Tombol | Aksi |
| --- | --- |
| `Ctrl+K` | Command palette |
| `Ctrl+N` | Chat baru |
| `Ctrl+Shift+N` | Proyek baru |
| `Ctrl+F` | Fokus pencarian chat |
| `Ctrl+,` | Pengaturan |
| `Ctrl+/` | Prompt library |
| `F1` | Buka panduan |
| `Ctrl+Shift+/` | Pintasan keyboard |
| `Ctrl+B` | Sembunyikan sidebar |
| `Esc` | Tutup lapisan teratas |

## Composer
| Tombol | Aksi |
| --- | --- |
| `Enter` | Kirim |
| `Shift+Enter` | Baris baru |
| `Ctrl+Enter` | Kirim (saat kirim-dengan-Enter mati) |
| `Esc` | Tutup popover |

## Chat
| Tombol | Aksi |
| --- | --- |
| `Ctrl+Shift+R` | Ulang balasan terakhir |
| `Ctrl+Shift+C` | Salin balasan terakhir |

## Daftar
`↑`/`↓` memindahkan pilihan palette, `Enter` menjalankannya. Di pencarian pengaturan, `Enter` melompat ke kontrol.

Sumber kebenaran tunggalnya `src/lib/shortcuts.ts` — jika sebuah pintasan ada di aplikasi, ia ada di artikel ini.
