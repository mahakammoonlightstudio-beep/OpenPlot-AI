# Story bible

The story bible is per project: characters, locations, items, factions, lore, timeline and outline entries.

## Entries
Each entry has a **kind**, a **title**, **content** (markdown), **tags** and optional **links** to other entries. One fact per entry is what makes retrieval work — a single "everything about the war" entry is hard to search and hard to keep current.

## Tools the model uses
With tools enabled the model can `search_story`, `read_story_bible`, `create_story_entry` and `update_story_entry`. Writes come back as a summary of what changed and the view refreshes itself.

## Attach to a chat
A chat bound to a project receives the project description as context. Pull a specific entry into the composer instead of dumping the whole bible.

## Good canon hygiene
- One subject per entry, named the way you would search for it.
- Update entries when the story changes; stale canon is worse than none.
- Use links for relationships instead of repeating text.
