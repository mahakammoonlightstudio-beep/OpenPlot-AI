# Keyboard shortcuts

## Global
| Keys | Action |
| --- | --- |
| `Ctrl+K` | Command palette |
| `Ctrl+N` | New chat |
| `Ctrl+Shift+N` | New project |
| `Ctrl+F` | Focus chat search |
| `Ctrl+,` | Settings |
| `Ctrl+/` | Prompt library |
| `F1` | Open the guide |
| `Ctrl+Shift+/` | Keyboard shortcuts |
| `Ctrl+B` | Toggle sidebar |
| `Esc` | Close the top layer |

## Composer
| Keys | Action |
| --- | --- |
| `Enter` | Send |
| `Shift+Enter` | New line |
| `Ctrl+Enter` | Send (when send-on-Enter is off) |
| `Esc` | Close popover |

## Chat
| Keys | Action |
| --- | --- |
| `Ctrl+Shift+R` | Regenerate the last reply |
| `Ctrl+Shift+C` | Copy the last reply |

## Lists
`↑`/`↓` move the palette selection, `Enter` runs it. In the settings search, `Enter` jumps to the control.

The single source of truth is `src/lib/shortcuts.ts` — if a shortcut exists in the app, it is in this article.
